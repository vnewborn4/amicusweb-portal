Frequently Asked Questions

Everything your legal, security, and engineering procurement teams need to know.

Who owns the intellectual property and code generated by Amicus?

You own 100% of the code and intellectual property. Under our enterprise terms, all synthesized code and architectural outputs are classified as Work-for-Hire with full, irrevocable assignment to the client. Amicus Technology Services Inc. retains zero claim over your IP.

Is our proprietary code or data ever used to train public AI models?

Never. We maintain contractual zero-data-retention agreements with all foundation model infrastructure partners. Your codebases, prompts, AST diffs, and project files are never logged for public model training or weight fine-tuning.

How does Amicus prevent hallucinations and broken code?

Amicus uses a deterministic Abstract Syntax Tree (AST) synthesis engine paired with an in-memory headless browser verification sandbox. Every synthesized layout is audited for semantic validity, CSS compatibility, and WCAG accessibility before output is accepted.

What is the Cryptographic Provenance Ledger?

Our SHA-256 cryptographic provenance ledger records the exact timestamp, prompt parameters, and hash of generated code in an immutable chain. This establishes verifiable proof of authorship and priority dates for patents and copyright defense.
